# অধ্যায় ৩: ব্রেইল এবং বাইনারি কোড (Braille and Binary Codes) — ডায়াগ্রাম ও চিত্রাবলী

### ডায়াগ্রাম ১: ব্রেইল সেলের গঠন ও ডট পজিশনিং (Braille Cell Architecture)
```
       [২×৩ বাইনারি সেল]
     
       কলাম ১     কলাম ২
      +-------+  +-------+
সারি ১ | ডট ১  |  | ডট ৪  |
      +-------+  +-------+
সারি ২ | ডট ২  |  | ডট ৫  |
      +-------+  +-------+
সারি ৩ | ডট ৩  |  | ডট ৬  |
      +-------+  +-------+

  প্রস্তুত বাইনারি রূপ: [ডট১, ডট২, ডট৩, ডট৪, ডট৫, ডট৬]
  অবস্থা: ১ (উঁচু/ON) অথবা ০ (সমতল/OFF)
```

---

### ডায়াগ্রাম ২: দৃষ্টিহীনদের পড়ার পদ্ধতির ইতিহাস (Historical Evolution)
```
  [১৭৮৪: ভ্যালেন্টিন হাঊই]
   └── উঁচু অক্ষরের ছাপা (Raised Latin Letters)
       └── সীমাবদ্ধতা: অতিরিক্ত জটিল এবং পড়ার গতি ধীর।
            │
            ▼
  [১৮১৯: চার্লস বারবিয়ার]
   └── নাইট রাইটিং (Night Writing / écriture nocturne)
       └── ১২-ডটের ধ্বনিভিত্তিক (Phonetic) সামরিক কোড।
       └── সীমাবদ্ধতা: আঙুলের ছোঁয়ায় পুরো সেল কভার হতো না।
            │
            ▼
  [১৮২৪: লুই ব্রেইল]
   └── ৬-ডটের বাইনারি ব্রেইল সেল (6-dot Binary Braille Cell)
       └── সুবিধা: আঙুলের ডগায় একবারে পঠিত, ৬৪টি সুনির্দিষ্ট বাইনারি কম্বিনেশন।
```

### ডায়াগ্রাম ৩: ব্রেইল বর্ণমালার ৩-স্তরের বিন্যাস (Systematic Derivation Matrix)

```
১ম সারি (a-j)  :  [ডট ১,২,৪,৫ ব্যবহার]   --->   a   b   c   d   e   f   g   h   i   j
                                                │   │   │   │   │   │   │   │   │   │
                                             +ডট ৩
                                                │   │   │   │   │   │   │   │   │   │
                                                ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼
২য় সারি (k-t)  :  [১ম সারি + ডট ৩]       --->   k   l   m   n   o   p   q   r   s   t
                                                │   │   │   │   │   │
                                             +ডট ৬
                                                │   │   │   │   │   │
                                                ▼   ▼   ▼   ▼   ▼   ▼
৩য় সারি (u-z)  :  [১ম সারি + ডট ৩ ও ৬]   --->   u   v   x   y   z  (w পরে যুক্ত)
```

### ডায়াগ্রাম ৪: শিফট এবং এস্কেপ কোডের স্টেট মেশিন (State Transition Diagram)

```
                   +----------------------------------+
                   |  স্বাভাবিক অক্ষরের মোড (Default) |
                   +----------------------------------+
                     │                              │
     [Number Indicator]                            [Capital Indicator]
     (ডট ৩,৪,৫,৬)                                   (ডট ৬)
                     │                              │
                     ▼                              ▼
    +----------------------------------+   +----------------------------------+
    |  সংখ্যা মোড (Numeric State)       |   | ১টি অক্ষর ক্যাপিটাল করার মোড    |
    |  (a->1, b->2, c->3 ... j->0)     |   | (Escape Mode - 1 Character Only) |
    +----------------------------------+   +----------------------------------+
                     │                              │
              [Space / Letter]                [অক্ষর পঠিত হওয়ার পর]
                     │                              │
                     +───────────────┬──────────────+
                                     │
                                     ▼
                   +----------------------------------+
                   |  স্বাভাবিক অক্ষরের মোড (Default) |
                   +----------------------------------+
```

### ডায়াগ্রাম ৫: ৬-বিট বাইনারি বিন্যাস ট্রি (Combinatorial 2^6 Tree)
```
                              [৬-ডটের সেলের অবস্থা]
                                       │
                      ┌────────────────┴────────────────┐
             ডট ১ (ON: 32)                    ডট ১ (OFF: 32)
              ┌──────┴──────┐                  ┌──────┴──────┐
          ডট ২ (ON)     ডট ২ (OFF)         ডট ২ (ON)     ডট ২ (OFF)
            ...            ...               ...            ...
   [মোট অনন্য বাইনারি কম্বিনেশন = 2 × 2 × 2 × 2 × 2 × 2 = 2^6 = 64 টি কোড]
```
