# অধ্যায় ৫: কোণ ঘুরে বার্তা পাঠানো — ভিজ্যুয়াল ডায়াগ্রাম (Visual Diagrams)

এই ফাইলটিতে ৫ম অধ্যায় (**"Seeing Around Corners"**) সম্পর্কিত সমস্ত গুরুত্বপূর্ণ সার্কিট নকশা, তার কমানোর ধাপসমূহ এবং ওহমের সূত্রের গাণিতিক চিত্র তুলে ধরা হলো।

---

## ডায়াগ্রাম ১: ১-মুখী ও ২-মুখী সার্কিটের বিবর্তন (Evolution of Wires)

### ক) ১-মুখী সার্কিট (২টি তার)
```
[আপনার ঘর]                                 [বন্ধুর ঘর]
  +---+
  | V |-----[ সুইচ (Switch) ]========(তার ১)========+
  +---+                                           |
    |                                        [ লাইটবাল্ব ]
    +=========================(তার ২)==============+
```

### খ) ২-মুখী স্বাধীন সার্কিট (৪টি তার)
```
[আপনার ঘর]                                 [বন্ধুর ঘর]
 (সুইচ ১) ========(তার ১)========> (বাল্ব ২)
 (বাল্ব ১) <=======(তার ২)======== (সুইচ ২)
 (ব্যাটারি ১) ====(তার ৩)======== (রিটার্ন ১)
 (রিটার্ন ২) ====(তার ৪)======== (ব্যাটারি ২)
```

---

## ডায়াগ্রাম ২: ৩-তার বিশিষ্ট শেয়ার্ড/কমন ওয়্যার সার্কিট (Common Wire Circuit)

```
[আপনার ঘর]                                         [বন্ধুর ঘর]
 (বাল্ব ১) <---+                                      +---> (বাল্ব ২)
              |                                      |
 (সুইচ ১) <---|-+                                  +-|---> (সুইচ ২)
              | |                                  | |
             ==============(তার ১: লাইন ১)==============
             ==============(তার ২: লাইন ২)==============
             ==============(তার ৩: কমন ওয়্যার)===========
             |                                       |
          (-)[ব্যাটারি ১](+)                     (-)[ব্যাটারি ২](+)
```

---

## ডায়াগ্রাম ৩: আর্থ গ্রাউন্ড ব্যবহার করে ১-তার ও ২-তার সার্কিট (Earth Ground System)

```
[আপনার ঘর]                                       [বন্ধুর ঘর]
  (+) [ব্যাটারি]
       |
    [সুইচ] ===========( একমাত্র দীর্ঘ তার )===========[ লাইটবাল্ব ]
       |                                                 |
      (-)                                                |
       |                                                 |
      ⏚ (আর্থ গ্রাউন্ড)                                  ⏚ (আর্থ গ্রাউন্ড)
  [তামার রড/পানির পাইপ]                            [তামার রড/পানির পাইপ]

========================================================================
                     মাটি / প্রথিবী (Ocean of Electrons)
========================================================================
```

## ডায়াগ্রাম ৫: সার্কিট সংযোগ ব্যবস্থার তুলনামূলক ম্যাট্রিক্স

```
+------------------+---------------+----------------+-----------------------+
| সার্কিটের ধরন     | তারের সংখ্যা  | খরচ কমানোর হার  | ব্যবহৃত প্রযুক্তি     |
+------------------+---------------+----------------+-----------------------+
| ২-মুখী পৃথক      | ৪টি তার       | 0%             | স্বাধীন ২টি লুপ       |
| কমন ওয়্যার       | ৩টি তার       | ২৫% হ্রাস      | শেয়ার্ড নেগেটিভ লাইন  |
| আর্থ গ্রাউন্ড    | ২টি তার       | ৫০% হ্রাস      | মাটি পরিবাহী হিসেবে   |
| একমুখী গ্রাউন্ড  | ১টি তার       | ৭৫% হ্রাস      | একক তার + গ্রাউন্ড   |
+------------------+---------------+----------------+-----------------------+
```
