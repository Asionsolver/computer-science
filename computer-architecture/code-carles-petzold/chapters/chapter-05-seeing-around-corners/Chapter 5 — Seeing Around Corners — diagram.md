# Chapter 5 — Seeing Around Corners: একনজরে ভিজ্যুয়াল ডায়াগ্রাম গাইড

> **মূল প্রতিপাদ্য:** ফ্ল্যাশলাইটের আলো সরলরেখায় চলে, তাই তা ঘরের কোণ বা বাঁক ঘুরে যেতে পারে না। এই সীমাবদ্ধতা কাটাতেই তার (Wire) ও বৈদ্যুতিক সার্কিটের আগমন। এই অধ্যায়ে শেখানো হয়েছে কীভাবে ৪টি তার থেকে শুরু করে ক্রমান্বয়ে কমন ওয়্যার (৩ তার), আর্থ গ্রাউন্ড (১ ও ২ তার) এবং সবশেষে রিলে (Relay) ব্যবহারের মাধ্যমে মাইলের পর মাইল দূরবর্তী যোগাযোগ সম্ভব হয়।

## ২. মূল সমস্যা: সরলরৈখিক দৃষ্টিসীমা (Line of Sight Problem)

**একনজরে:** ফ্ল্যাশলাইটের আলো কেবল তখনই দেখা যায় যখন প্রেরক ও গ্রাহক সরাসরি মুখোমুখি থাকে।

```mermaid
flowchart LR
    A["🏠 বন্ধু A (প্রেরক)<br/>🔦 ফ্ল্যাশলাইট"] -->|"সরলরৈখিক আলোর রশ্মি (Line of Sight)"| B["🏠 বন্ধু B (গ্রাহক)<br/>👁️ চোখ"]
```

- **সীমাবদ্ধতা:** মাঝে কোনো দেয়াল, বাড়ি, গাছ বা কুয়াশা থাকলে আলো পৌঁছায় না।

## ৩. কোণ ঘোরার সমস্যা (The Corner Problem)

**একনজরে:** আলো বাঁক নিতে পারে না। বন্ধুর ঘর যদি রাস্তার মোড়ে বা দেয়ালের পেছনে হয়, ফ্ল্যাশলাইট সম্পূর্ণ অকেজো।

```mermaid
flowchart TD
    subgraph CornerProblem ["কোণ ঘোরার সমস্যা (The Corner Problem)"]
        direction LR
        A["🏠 বন্ধু A<br/>🔦 আলো ছড়ায়"] -->|"আলো সোজা যায়"| Wall["🧱 দেয়াল / রাস্তার মোড়<br/>❌ আলো আটকে যায়!"]
        Wall -.->|"❌ আলো কোণ ঘুরতে পারে না"| B["🏠 বন্ধু B<br/>👁️ আলো দেখতে পায় না"]
    end
```

## ৪. তারভিত্তিক সমাধান: ইলেকট্রিক্যাল সার্কিট (Wire-Based Solution)

**একনজরে:** আলো বাঁক নিতে পারে না, কিন্তু **তামার তার (Copper Wire) যেকোনো দিকে বাঁকানো যায়** এবং ইলেকট্রন তারের ভেতর দিয়ে বাঁক ঘুরে পৌঁছে যায়।

```mermaid
flowchart LR
    subgraph HouseA ["🏠 ঘর A (প্রেরক)"]
        Bat["🔋 ব্যাটারি (+)"]
        Sw["সুইচ / চাবি [Key]"]
    end

    subgraph HouseB ["🏠 ঘর B (গ্রাহক)"]
        Bulb["💡 লাইটবাল্ব"]
    end

    Bat -->|"বিদ্যুৎ প্রবাহ"| Sw
    Sw -->|"১. যাওয়ার লম্বা তার (কোণ বা দেয়াল ঘুরে)"| Bulb
    Bulb -->|"২. ফেরার তার (সম্পূর্ণ Closed Loop)"| Bat
```

> **মূল নীতি:** বিদ্যুৎ চলার জন্য সবসময় একটি **সম্পূর্ণ বদ্ধ লুপ (Closed Loop)** দরকার। শুধু একটি তার দিয়ে পৌঁছালেই হবে না, ব্যাটারির অপর প্রান্তে ফিরে আসার পথও থাকতে হবে।

## ৫. বিদ্যুতের মাধ্যমে মোর্স কোড (Morse Code via Electricity)

**একনজরে:** সুইচে চাপ দেওয়ার সময়কাল দিয়ে ডট (.) ও ড্যাশ (-) তৈরি হয়, যা দূরবর্তী বাল্বে আলো বা শব্দ হিসেবে প্রকাশ পায়।

```mermaid
flowchart TD
    Key["টেলিগ্রাফ চাবি প্রেস"]
    Key -->|"স্বল্পস্থায়ী চাপ (১ ইউনিট)"| Dot["ডট (.) ➔ ক্ষণস্থায়ী আলো 💡"]
    Key -->|"দীর্ঘস্থায়ী চাপ (৩ ইউনিট)"| Dash["ড্যাশ (-) ➔ দীর্ঘস্থায়ী আলো 💡💡💡"]
```

## ৬. একমুখী যোগাযোগ সার্কিট (One-Way Circuit — ২ তার)

**একনজরে:** A থেকে B-তে খবর পাঠাতে ২টি লম্বা তার প্রয়োজন (১টি যাওয়ার + ১টি ফেরার)।

![একমুখী টেলিগ্রাফ সার্কিট](diagrams/01a-one-way.svg)

```mermaid
flowchart LR
    subgraph Sender ["ঘর A: প্রেরক"]
        BatA["🔋 ব্যাটারি"] --> KeyA["সুইচ [Key A]"]
    end

    subgraph Receiver ["ঘর B: গ্রাহক"]
        BulbB["💡 Bulb B"]
    end

    KeyA -->|"তার ১ (আউটগোয়িং সিগন্যাল)"| BulbB
    BulbB -->|"তার ২ (রিটার্ন তার)"| BatA
```

- **তারের সংখ্যা:** ২টি লম্বা তার।
- **সীমাবদ্ধতা:** B কেবল বার্তা দেখতে পারে, কিন্তু A-কে উত্তর পাঠাতে পারে না।

## ৭. দ্বিমুখী যোগাযোগের প্রাথমিক ধারণা (Bidirectional Concept)

**একনজরে:** দুই বন্ধুকেই বার্তা পাঠাতে ও গ্রহণ করতে হলে দুটি পৃথক একমুখী সার্কিট প্রয়োজন।

```mermaid
flowchart LR
    subgraph Line1 ["চ্যানেল ১: A পাঠায় B-কে"]
        direction LR
        KeyA["ঘর A: Key A"] -->|"তারের সিগন্যাল"| BulbB["ঘর B: Bulb B 💡"]
    end

    subgraph Line2 ["চ্যানেল ২: B পাঠায় A-কে"]
        direction LR
        KeyB["ঘর B: Key B"] -->|"তারের সিগন্যাল"| BulbA["ঘর A: Bulb A 💡"]
    end
```

## ৮. ৪-তারের দ্বিমুখী ব্যবস্থা (4-Wire Bidirectional System)

**একনজরে:** দুটি সম্পূর্ণ স্বাধীন সার্কিট। প্রতিটি সার্কিটে ২টি করে মোট **৪টি লম্বা তার** লাগে।

![দ্বিমুখী ৪-তারের সার্কিট](diagrams/01b-two-way.svg)

```mermaid
flowchart LR
    subgraph Circuit1 ["সার্কিট ১ (A ➔ B)"]
        direction LR
        A1["Key A"] -->|"তার ১ (সিগন্যাল)"| B1["Bulb B 💡"]
        B1 -->|"তার ২ (রিটার্ন)"| A1
    end

    subgraph Circuit2 ["সার্কিট ২ (B ➔ A)"]
        direction LR
        B2["Key B"] -->|"তার ৩ (সিগন্যাল)"| A2["Bulb A 💡"]
        A2 -->|"তার ৪ (রিটার্ন)"| B2
    end
```

- **তারের সংখ্যা:** মোট ৪টি লম্বা তার।
- **সমস্যা:** দীর্ঘ দূরত্বে ৪টি তার টানা অত্যন্ত ব্যয়বহুল, ভারী এবং জটিল।

## ৯. কমন ওয়্যার ব্যবস্থা (3-Wire System — কমন রিটার্ন তার)

**একনজরে:** দুটি সার্কিটের নেগেটিভ (-) টার্মিনালকে একটিমাত্র তারে যুক্ত করে **১টি তার বাঁচানো যায়** (৪টি তার ➔ ৩টি তার, ২৫% সাশ্রয়)।

![কমন ওয়্যার ৩-তারের সার্কিট](diagrams/02-common-wire.svg)

```mermaid
flowchart LR
    subgraph House_A ["ঘর A"]
        KA["Key A"]
        BA["Bulb A 💡"]
        BatA["ব্যাটারি A (-)"]
    end

    subgraph House_B ["ঘর B"]
        KB["Key B"]
        BB["Bulb B 💡"]
        BatB["ব্যাটারি B (-)"]
    end

    KA -->|"তার ১ (সিগন্যাল A → B)"| BB
    KB -->|"তার ২ (সিগন্যাল B → A)"| BA
    BatA -.->|"তার ৩ (শেয়ার্ড কমন রিটার্ন তার)"| BatB
```

### ট্রুথ টেবিল (Truth Table):

| Key A  | Key B  | কোন বাল্ব জ্বলে? | কমন তারের অবস্থা                                             |
| :----: | :----: | :--------------: | :----------------------------------------------------------- |
|  OFF   |  OFF   |    কোনোটিই নয়    | বিদ্যুৎ নেই                                                  |
| **ON** |  OFF   |    **Bulb B**    | A-এর রিটার্ন বিদ্যুৎ বহন করে                                 |
|  OFF   | **ON** |    **Bulb A**    | B-এর রিটার্ন বিদ্যুৎ বহন করে                                 |
| **ON** | **ON** |    **দুটোই**     | দুই দিকের কারেন্ট কাটাকাটি হয়ে কমন তারে কারেন্ট প্রায় শূন্য! |

## ১০. আর্থ গ্রাউন্ড রিটার্ন (Earth as Conductor — ১ ও ২ তারের বিপ্লব)

## ১১. গ্রাউন্ড ও আর্থের পার্থক্য (Ground vs Earth)

**একনজরে:** দৈনন্দিন সার্কিটে গ্রাউন্ড মানে কমন রেফারেন্স পয়েন্ট; টেলিগ্রাফে গ্রাউন্ড মানে আক্ষরিক অর্থেই আমাদের পায়ের নিচের মাটি।

| ধরন                                   | প্রতীক | অর্থ                          | ভূমিকা                                                 |
| :------------------------------------ | :----: | :---------------------------- | :----------------------------------------------------- |
| **আর্থ গ্রাউন্ড (Earth Ground)**      |  `⏚`   | মাটির সাথে সরাসরি সংযোগ       | মাটিকে পরিবাহী হিসেবে ব্যবহার করে সার্কিট সম্পূর্ণ করা |
| **চেসিস গ্রাউন্ড (Chassis Ground)**   |  `⌸`   | ধাতব ফ্রেমের সাথে সংযোগ       | গাড়ির বডি বা মেটাল কেসিংকে কমন ওয়্যার হিসেবে ব্যবহার   |
| **সিগন্যাল গ্রাউন্ড (Signal Ground)** |  `▽`   | সার্কিটের 0V রেফারেন্স পয়েন্ট | সমস্ত ভোল্টেজ পরিমাপের বেসলাইন (রেফারেন্স লেভেল)       |

## ১২. ইলেকট্রনের মহাসমুদ্র: আর্থের ধারণা (Earth as Electron Reservoir)

**একনজরে:** সমুদ্র থেকে এক বালতি পানি তুললে বা ঢাললে যেমন সমুদ্রের পানির স্তর বদলায় না, তেমনি পৃথিবীতে কোটি কোটি ইলেকট্রন ঢাললেও বা নিলেও পৃথিবীর চার্জ শূন্য (0V) থাকে।

```mermaid
flowchart TD
    Earth["🌍 <b>পৃথিবী (Earth Reservoir)</b><br/>ইলেকট্রনের এক সীমাহীন মহাসমুদ্র (সর্বদা 0V রেফারেন্স)"]

    Sink["📥 <b>ইলেকট্রন গ্রহণ (Sink)</b><br/>সার্কিট থেকে অতিরিক্ত ইলেকট্রন মাটিতে চলে যায়"]
    Source["📤 <b>ইলেকট্রন সরবরাহ (Source)</b><br/>সার্কিটে ঘাটতি হলে মাটি থেকে ইলেকট্রন উঠে আসে"]

    Sink -->|"অতিরিক্ত ইলেকট্রন শোষণ করে"| Earth
    Earth -->|"প্রয়োজনমতো ইলেকট্রন যোগায়"| Source
```

## ১৯. দূরপাল্লার সমাধান: অটোমেটিক রিলে (The Relay Solution)

## ২০. টেলিগ্রাফ সাউন্ডার: আলো থেকে শব্দে রূপান্তর (Telegraph Sounder)

**একনজরে:** দিনের আলোতে বাল্বের আলো দেখা কঠিন এবং বাল্ব জ্বলতে-নিভতে সামান্য সময় নেয়। তাই বাল্ব সরিয়ে **শব্দ তৈরি করার যন্ত্র (সাউন্ডার)** ব্যবহার করা হয়।

```mermaid
flowchart TD
    Key["টেলিগ্রাফ চাবি প্রেস (কারেন্ট ON)"] --> Mag["ইলেক্ট্রোম্যাগনেট সক্রিয়"] --> Down["লোহার বার নিচে টানে ➔ 'ক্লিক' (CLICK)"]
    Release["চাবি ছেড়ে দেওয়া (কারেন্ট OFF)"] --> Spring["স্প্রিং বারকে ওপরে তোলে"] --> Up["ধাতব ফ্রেমে আঘাত ➔ 'ক্ল্যাক' (CLACK)"]
```

### মোর্স কোডের শ্রুতিগ্রাহ্য রূপ:

- **ডট (.):** দ্রুত `ক্লিক-ক্ল্যাক` (CLICK-CLACK)
- **ড্যাশ (-):** ব্যবধানযুক্ত `ক্লিক ... ক্ল্যাক` (CLICK ... CLACK)
- **সুবিধা:** অপারেটরকে সারাক্ষণ তাকিয়ে থাকতে হয় না; কান দিয়ে শুনে হাত দিয়ে সরাসরি কাগজে বার্তা লিখে ফেলা যায়।
