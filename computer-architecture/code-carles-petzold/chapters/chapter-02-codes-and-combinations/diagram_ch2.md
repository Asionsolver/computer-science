# অধ্যায় ২: কোড এবং বিন্যাস (Codes and Combinations) — ভিজ্যুয়াল ডায়াগ্রাম

## ১. ডিকোডিং সমস্যার চিত্রায়ন (The Decoding Problem)

```
[প্রেরক / Sender]
  অক্ষর (Alphabet) 'Y'  ===> [তালিকা অনুসরণ] ===>  মোর্স সংকেত: -.--
  
[গ্রাহক / Receiver]
  সংকেত প্রাপ্তি: -.--  ===> [বর্ণানুক্রমিক টেবিল স্ক্যান]
                           A ? না
                           B ? না
                           ...
                           Y ? হ্যাঁ! (ধীরগতির প্রক্রিয়া)
```

## ২. সংকেতের দৈর্ঘ্য অনুযায়ী কম্বিনেশন টেবিল (Exponential Table Structure)

```
+-----------------------------------------------------------------------+
|  দৈর্ঘ্য (Length) |  সূচক (Exponent)  |  সম্ভাব্য কোডের সংখ্যা (Codes)    |
+-----------------------------------------------------------------------+
|  ১ সংকেত ( . / - )|      2^1          |  ২ টি ( E, T )                    |
|  ২ সংকেত ( .. / -)|      2^2          |  ৪ টি ( I, A, N, M )              |
|  ৩ সংকেত          |      2^3          |  ৮ টি ( S, U, R, W, D, K, G, O )   |
|  ৪ সংকেত          |      2^4          |  ১৬ টি ( H, V, F, B, C, Y, Z ...) |
+-----------------------------------------------------------------------+
|  মোট ৪ টেবিলে কোড সংখ্যা: ২ + ৪ + ৮ + ১৬ = ৩০ টি (২৬ অক্ষর + ৪ বিশেষ চিহ্ন) |
+-----------------------------------------------------------------------+
```

## ৩. মোর্স কোড ডিকোডিং বাইনারি ট্রি (Binary Decision Tree Diagram)

```
                          [ শুরু / START ]
                             /        \
                            /          \
                        ( Dot )       ( Dash )
                          /              \
                         E                T
                       /   \            /   \
                      .     -          .     -
                     I       A        N       M
                    / \     / \      / \     / \
                   S   U   R   W    D   K   G   O
                  /\  /\  /\  /\   /\  /\  /\  /\
                 H V F Ü L Ä P J  B X C Y Z Q Ö §
```

### সংকেত ট্র্যাকিং উদাহরণ (`.-.`):
1. START $\rightarrow$ **Dot (`.`)** $\rightarrow$ Node **E**
2. Node **E** $\rightarrow$ **Dash (`-`)** $\rightarrow$ Node **A**
3. Node **A** $\rightarrow$ **Dot (`.`)** $\rightarrow$ Node **R** (চূড়ান্ত অক্ষর: **R**)

## ৫. বাইনারি ব্যবস্থার তুলনা (Binary Equivalences)

```
+------------------+------------------+------------------+
|   কয়েন (Coin)    | ফ্ল্যাশলাইট (Light)|   মোর্স কোড      |
+------------------+------------------+------------------+
|   Head (হেড)     |    ON (আলো জ্বালা) |   Dot  ( . )     |
|   Tail (টেইল)    |    OFF (আলো নেভা) |   Dash ( - )     |
+------------------+------------------+------------------+
|  দ্বৈত অবস্থা    |   দ্বৈত অবস্থা    |   দ্বৈত উপাদান   |
+------------------+------------------+------------------+
```
