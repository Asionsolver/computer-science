# Chapter 1 — Best Friends
## Glossary

এই Glossary-তে Chapter 1-এর গুরুত্বপূর্ণ Technical এবং Conceptual Terms-এর সহজ বাংলা ব্যাখ্যা দেওয়া হয়েছে।

---

## 1. Code

**Meaning:**  
কোনো Information-কে নির্দিষ্ট Symbol, Signal বা Pattern ব্যবহার করে Represent করার একটি System।

**সহজভাবে:**  
একটি Information-কে অন্য একটি বোঝার মতো Form-এ প্রকাশ করার নিয়মকে Code বলা যায়।

**Example:**  
Morse Code-এ Letter-কে Dot এবং Dash-এর Combination দিয়ে প্রকাশ করা হয়।

---

## 2. Morse Code

**Meaning:**  
Dot এবং Dash ব্যবহার করে Letters, Numbers এবং কিছু Punctuation বা Signal Represent করার একটি Code System।

**Basic Structure:**

```text
Short Signal → Dot (.)
Long Signal  → Dash (-)
```

**Example:**

```text
A → .-
B → -...
S → ...
O → ---
```

**Important:**  
Morse Code-এর মূল ধারণা হলো অল্প কয়েক ধরনের Signal-এর Combination ব্যবহার করে অনেক Information প্রকাশ করা।

---

## 3. Signal

**Meaning:**  
Information বহন বা Communicate করার জন্য ব্যবহৃত কোনো Physical পরিবর্তন বা Pattern।

**এই Chapter-এ:**  
Flashlight-এর আলো জ্বলা এবং নিভে যাওয়ার মাধ্যমে Signal তৈরি করা হয়।

**Example:**

```text
Short Blink → Signal
Long Blink  → Signal
```

---

## 4. Blink

**Meaning:**  
Flashlight-এর আলো অল্প সময়ের জন্য জ্বালানো বা বন্ধ করা।

**Chapter-এর Context:**

```text
Short Blink → Dot
Long Blink  → Dash
```

Blink-এর Duration বা সময়ের পার্থক্য Information বহন করে।

---

## 5. Dot

**Symbol:**

```text
.
```

**Meaning:**  
Morse Code-এ একটি Short Signal বা Short Blink-কে Dot বলা হয়।

**Example:**

```text
S → ...
```

এখানে তিনটি Short Blink রয়েছে।

---

## 6. Dash

**Symbol:**

```text
-
```

**Meaning:**  
Morse Code-এ একটি Long Signal বা Long Blink-কে Dash বলা হয়।

**Example:**

```text
O → ---
```

এখানে তিনটি Long Blink রয়েছে।

---

## 7. Representation

**Meaning:**  
কোনো Information বা Object-কে অন্য কোনো Form বা Symbol ব্যবহার করে প্রকাশ করা।

**Chapter-এর গুরুত্বপূর্ণ ধারণা:**  
Flashlight-এর বাস্তব আলো নিজে Dot বা Dash নয়। Dot এবং Dash হলো সেই আলো বা Blink-এর **Representation**।

```text
Actual Physical Signal
        ↓
Short / Long Blink
        ↓
Dot / Dash Representation
```

---

## 8. Information

**Meaning:**  
যে Meaning বা Data আমরা একে অপরের কাছে Communicate করতে চাই।

**Chapter-এর Example:**

```text
Letters
Numbers
Punctuation
Messages
Signals
```

পরবর্তী Computer-related ধারণাগুলোর ক্ষেত্রে Information আরও বিভিন্ন ধরনের হতে পারে।

---

## 9. Communication

**Meaning:**  
একজন ব্যক্তি বা System থেকে অন্য ব্যক্তি বা System-এর কাছে Information পৌঁছে দেওয়ার প্রক্রিয়া।

**Chapter-এর Example:**

```text
Person A
   ↓
Flashlight Signal
   ↓
Person B
```

এখানে Flashlight ব্যবহার করে দুই বন্ধু Information Communicate করছে।

---

## 10. Encode

**Meaning:**  
Information-কে একটি নির্দিষ্ট Code বা Representation-এ Convert করার প্রক্রিয়া।

**Example:**

```text
Letter
  ↓
Morse Code
  ↓
Dot + Dash
```

যেমন:

```text
A → .-
```

এখানে `A`-কে `.-`-এ Convert করা হলো।

---

## 11. Decode

**Meaning:**  
Code বা Representation থেকে আবার Original Information বোঝার প্রক্রিয়া।

**Example:**

```text
.- 
↓
A
```

অর্থাৎ Dot এবং Dash দেখে Receiver বুঝতে পারে যে এটি `A`।

---

## 12. Receiver

**Meaning:**  
যে ব্যক্তি বা System কোনো Signal বা Information গ্রহণ করে।

**Chapter-এর Example:**

```text
Sender
   ↓
Flashlight Signal
   ↓
Receiver
```

যে বন্ধু Flashlight-এর Signal দেখছে, সে Receiver।

---

## 13. Sender

**Meaning:**  
যে ব্যক্তি বা System Information বা Signal পাঠায়।

**Chapter-এর Example:**

```text
Sender
   ↓
Flashlight
   ↓
Signal
```

যে বন্ধু Flashlight ব্যবহার করে Message পাঠাচ্ছে, সে Sender।

---

## 14. Timing

**Meaning:**  
Signal কতক্ষণ স্থায়ী হচ্ছে বা কখন Signal দেওয়া হচ্ছে—তার সময়গত নিয়ম।

**Morse Code-এর ক্ষেত্রে:**  
Short এবং Long Signal-এর পার্থক্য Timing-এর উপর নির্ভর করে।

```text
Short Duration → Dot
Long Duration  → Dash
```

---

## 15. Pause

**Meaning:**  
দুটি Signal-এর মধ্যে থাকা নির্দিষ্ট সময়ের বিরতি।

**গুরুত্ব:**  
শুধু Dot এবং Dash যথেষ্ট নয়। Signal-এর মধ্যে Pause-ও Message বোঝার ক্ষেত্রে গুরুত্বপূর্ণ।

Conceptually:

```text
Signal → Pause → Signal → Pause → Signal
```

---

## 16. Pattern

**Meaning:**  
একাধিক Signal বা Symbol একটি নির্দিষ্ট Order-এ সাজানো হলে যে Structure তৈরি হয়।

**Example:**

```text
... 
```

এই Pattern Morse Code-এ `S` Represent করে।

আর:

```text
---
```

`O` Represent করে।

---

## 17. Symbol

**Meaning:**  
কোনো Information বা Meaning Represent করার জন্য ব্যবহৃত একটি চিহ্ন।

**Example:**

```text
. → Dot
- → Dash
```

Dot এবং Dash হলো Morse Code-এর গুরুত্বপূর্ণ Symbols।

---

## 18. Binary

**Meaning:**  
মাত্র দুইটি সম্ভাব্য State বা Value ব্যবহার করে Information Represent করার পদ্ধতি।

সাধারণভাবে:

```text
0
1
```

Chapter 1-এ Morse Code-এর মাধ্যমে Binary-এর একটি গুরুত্বপূর্ণ ধারণার ভিত্তি তৈরি করা হয়:

```text
Two Possible States
        ↓
Combination
        ↓
More Information
```

**Note:**  
এই Chapter-এ Binary Computer-এর সম্পূর্ণ Technical Explanation দেওয়া হয় না; বরং দুই ধরনের Signal কীভাবে অনেক Information প্রকাশ করতে পারে সেই ধারণার দিকে নিয়ে যাওয়া হয়।

---

## 19. Two States

**Meaning:**  
কোনো System-এ দুটি আলাদা সম্ভাব্য অবস্থা থাকা।

Chapter-এর Flashlight example-এ:

```text
Short
Long
```

এই দুই ধরনের Signal ব্যবহার করে বিভিন্ন Combination তৈরি করা যায়।

পরবর্তীতে Computer-এর ক্ষেত্রে এই ধারণাটি আরও গুরুত্বপূর্ণ হয়ে ওঠে।

---

## 20. Combination

**Meaning:**  
কয়েকটি Simple Element-কে বিভিন্নভাবে সাজিয়ে নতুন Pattern বা Information তৈরি করা।

**Example:**

দুটি Element:

```text
Dot
Dash
```

এগুলো বিভিন্নভাবে Combine করা যায়:

```text
.
-
..
.-
-.
--
```

Element-এর সংখ্যা বাড়ার সঙ্গে সঙ্গে সম্ভাব্য Combination-এর সংখ্যাও বাড়ে।

---

## 21. Powers of Two

যখন প্রতিটি Position-এর জন্য দুইটি সম্ভাব্য Choice থাকে, তখন Position বাড়ার সঙ্গে সঙ্গে সম্ভাব্য Combination দ্রুত বাড়ে।

```text
1 Position  → 2
2 Positions → 4
3 Positions → 8
4 Positions → 16
5 Positions → 32
6 Positions → 64
```

General Formula:

```text
Number of Combinations = 2ⁿ
```

যেখানে `n` = Position-এর সংখ্যা।

---

## 22. Common Letter

**Meaning:**  
যে Letter কোনো Language-এ তুলনামূলকভাবে বেশি ব্যবহৃত হয়।

Morse Code-এর ক্ষেত্রে বেশি ব্যবহৃত Letters-এর জন্য তুলনামূলকভাবে ছোট Code ব্যবহার করা হয়।

**মূল ধারণা:**

```text
Common Letter → Shorter Code
Rare Letter   → Longer Code
```

এর ফলে সাধারণ Message পাঠানোর সময় কম Signal প্রয়োজন হতে পারে।

---

## 23. Rare Letter

**Meaning:**  
যে Letter তুলনামূলকভাবে কম ব্যবহৃত হয়।

Morse Code-এ এমন Letters-এর Code সাধারণত বেশি দীর্ঘ হতে পারে।

---

## 24. Punctuation

**Meaning:**  
লিখিত ভাষায় Sentence বা বক্তব্যের Structure এবং Meaning বোঝাতে ব্যবহৃত বিশেষ চিহ্ন।

**Example:**

```text
.
,
?
```

Morse Code শুধু Alphabet-এর Letters নয়, Numbers এবং কিছু Punctuation-ও Represent করতে পারে।

---

## 25. SOS

**Morse Representation:**

```text
... --- ...
```

এটি Chapter-এ একটি পরিচিত Morse Signal-এর Example হিসেবে ব্যবহৃত হয়েছে।

Breakdown:

```text
S → ...
O → ---
S → ...
```

---

## 26. Stenography

**Meaning:**  
দ্রুত Speech বা Information লিখে রাখার জন্য ব্যবহৃত একটি Shortened Writing System বা পদ্ধতি।

Chapter-এ এটি Code-এর broader idea বোঝানোর উদাহরণ হিসেবে আসে।

---

## 27. Shorthand

**Meaning:**  
দ্রুত লেখার জন্য Words বা Sounds-কে সংক্ষিপ্ত Symbol বা Form-এ প্রকাশ করার পদ্ধতি।

এটিও Information Representation-এর একটি উদাহরণ।

---

## 28. Braille

**Meaning:**  
স্পর্শের মাধ্যমে পড়ার জন্য ব্যবহৃত একটি Writing System, যেখানে Raised Dots-এর Pattern ব্যবহার করা হয়।

এটি দেখায় যে Information শুধুমাত্র Sound বা Visual Signal-এর মাধ্যমে নয়, Touch-এর মাধ্যমেও Represent করা যায়।

---

## 29. Visual Information

**Meaning:**  
চোখের মাধ্যমে উপলব্ধ Information।

**Example:**

```text
Pictures
Images
Visual Patterns
```

Chapter-এর শেষদিকে Computer-কে বিভিন্ন ধরনের Information Represent করতে হয়—এর মধ্যে Visual Information-ও রয়েছে।

---

## 30. Aural Information

**Meaning:**  
শ্রবণের মাধ্যমে উপলব্ধ Information।

**Example:**

```text
Speech
Sound
Music
```

Computer-এর ক্ষেত্রে এই ধরনের Information-ও Code বা Representation-এর মাধ্যমে প্রকাশ করতে হয়।

---

## 31. Code System

**Meaning:**  
একটি নির্দিষ্ট Rule অনুসরণ করে Information Represent করার সম্পূর্ণ ব্যবস্থা।

Morse Code একটি Code System, কারণ এখানে:

```text
Information
    ↓
Rules
    ↓
Dot + Dash Patterns
    ↓
Represented Message
```

# Must Remember

Chapter 1 থেকে অবশ্যই মনে রাখবে:

1. **Code মানেই Secret Code নয়।** Code Information Represent এবং Communicate করার একটি System হতে পারে।
2. **Morse Code = Dot + Dash-এর Combination।**
3. Dot এবং Dash আসলে Flashlight-এর **Short এবং Long Signal-এর Representation**।
4. **Timing এবং Pause** Communication-এর গুরুত্বপূর্ণ অংশ।
5. বেশি ব্যবহৃত Letter-এর জন্য ছোট Code ব্যবহার করা যায়।
6. মাত্র **দুই ধরনের Possibility** ব্যবহার করেও অনেক Information Represent করা সম্ভব।
7. `n`টি দুই-সম্ভাবনাময় Position থেকে `2ⁿ`টি Combination তৈরি করা যায়।
8. এই Simple Two-State ধারণাই পরবর্তীতে **Binary এবং Computer-এর Information Representation** বোঝার ভিত্তি তৈরি করবে।
