# Chapter 1: Best Friends - Visual Diagrams & Flowcharts

চার্লস পেটজোল্ডের **"Code"** বইটির প্রথম অধ্যায় **"Best Friends"**-এর মূল বিষয়বস্তুগুলোকে দৃশ্যমান ও সহজে বোঝার সুবিধার্থে নিচের ডায়াগ্রাম, ফ্লোচার্ট ও টাইমলাইন সাজানো হলো।

## ১. যোগাযোগের দৃশ্যপট (Communication Scenario)

রাস্তার দুই পাশের দুটি ঘরের জানালা দিয়ে ফ্ল্যাশলাইটের আলোর সাহায্যে দুজন বন্ধুর গোপন যোগাযোগের অবকাঠামো:

```
+------------------------------------+               +------------------------------------+
|            আপনার ঘর                |               |           বন্ধুর ঘর                |
|           (Sender)                 |               |          (Receiver)                |
|                                    |               |                                    |
|    [আপনার চোখ / মস্তিষ্ক]          |               |    [বন্ধুর চোখ / মস্তিষ্ক]          |
|              |                     |               |              ^                     |
|              v                     |               |              |                     |
|      [ফ্ল্যাশলাইট (Light)]          |  ==== আলো ===>|     [খোলা জানালা (Window)]          |
|              |                     | (Light Signal)|              |                     |
|              v                     |               |              v                     |
|       [খোলা জানালা]                |               |     [বার্তা ডিকোদিং]               |
+------------------------------------+               +------------------------------------+
                  \                                             /
                   \__________________ রাস্তা __________________/
```

## ৩. মোর্স কোড টাইমিং ডায়াগ্রাম (Morse Code Timing Diagram)

মোর্স কোডে সংকেত অন/অফ এবং বিরতির নির্ভুল সময়সীমা:

```
সংকেতের ধরণ (Signals):
Dot  ( . ) : [ON]             (১ ইউনিট সময়)
Dash ( - ) : [ON][ON][ON]     (৩ ইউনিট সময় = ৩টি ডট)

বিরতির সময়সীমা (Pauses / Light OFF):
অক্ষরের ভেতরে  (Intra-character) : [OFF]             (১ ইউনিট)
অক্ষর থেকে অক্ষর (Inter-character) : [OFF][OFF][OFF]     (৩ ইউনিট)
শব্দ থেকে শব্দ   (Inter-word)      : [OFF][OFF][OFF][OFF][OFF][OFF] (৬-৭ ইউনিট)
```

### উদাহরণ: "SOS" সংকেতের টাইমিং ডায়াগ্রাম
`S = . . .` | `O = - - -` | `S = . . .`

```
  --- S ---       --- O ---       --- S ---
  .   .   .       -   -   -       .   .   .
 ┌─┐ ┌─┐ ┌─┐     ┌───┐───┐───┐   ┌─┐ ┌─┐ ┌─┐
 │ │ │ │ │ │     │   │   │   │   │ │ │ │ │ │
─┘ └─┘ └─┘ └─────┘   └───└───└───┘ └─┘ └─┘ └─
  1 1 1 1 1   3    3 1 3 1 3   3  1 1 1 1 1
```

## ৪. মোর্স কোড বাইনারি ট্রি ডায়াগ্রাম (Morse Code Binary Decision Tree)

সংকেত থেকে অক্ষরে পৌঁছানোর সিদ্ধান্ত বৃক্ষ (Dot বামে, Dash ডানে):

```
                                  [START]
                                 /       \
                                /         \
                         (Dot) /           \ (Dash)
                              /             \
                             E               T
                           /   \           /   \
                         (.)   (-)       (.)   (-)
                         /       \       /       \
                        I         A     N         M
                       / \       / \   / \       / \
                      S   U     R   W D   K     G   O
```

## ৫. সাধারণ ব্লিঙ্ক বনাম মোর্স কোডের তুলনামূলক ফ্লোচার্ট

```
[বার্তা: "HOW ARE YOU?"]
         │
         ├─────────────────────────────────────────┐
         ▼                                         ▼
 [পদ্ধতি ১: সংখ্যানুযায়ী ব্লিঙ্ক]          [পদ্ধতি ২: মোর্স কোড]
 H (8) + O (15) + W (23) = 46               H (....) + O (---) + W (.--)
 A (1) + R (18) + E (5)  = 24               A (.-) + R (.-.) + E (.)
 Y (25) + O (15) + U (21) = 61              Y (-.--)+ O (---) + U (..-)
         │                                         │
         ▼                                         ▼
   মোট ১৩১টি ব্লিঙ্ক                          মোট ৩২টি সংকেত
 (অত্যন্ত ধীর ও ক্লান্তিকর)                 (দ্রুত ও দক্ষ সংকেত)
```

## ৬. কম্যুনিকেশন সিস্টেম ডায়াগ্রাম (Communication System Model)

শ্যানন-এর কম্যুনিকেশন মডেল অনুযায়ী ১ম অধ্যায়ের আলো নির্ভর সিস্টেম:

```
 [তথ্য উৎস]  ──>  [ট্রান্সমিটার]  ──>  [চ্যানেল]  ──>  [রিসিভার]  ──>  [গন্তব্য]
(Information)     (Transmitter)     (Channel)     (Receiver)     (Destination)
    │                  │               │              │               │
  চিন্তা            ফ্ল্যাশলাইট       রাস্তার আলো/বাতাস     চোখ          বন্ধুর মস্তিষ্ক
 ("How are you")   (Dot/Dash Signal)  (Light Waves)    (Visual Sensor)  (Decoded Message)
```
